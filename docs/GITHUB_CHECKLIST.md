# GitHub Publication Checklist

## Before pushing

- [ ] Replace `YOUR_USERNAME` in README clone URL
- [ ] Add 3-5 screenshots to `assets/`
- [ ] Add a short demo GIF if available
- [ ] Confirm `.env` is ignored
- [ ] Confirm no API key or credential appears in tracked files
- [ ] Run `python -m py_compile app.py`
- [ ] Run the Streamlit app locally
- [ ] Verify dashboard, forecast, investigation, and data-quality tabs
- [ ] Run the test suite if the environment contains pytest

## Recommended repository settings

- Repository name: `TowerIQ`
- Description: `AI-powered telecom tower intelligence platform for data quality, operational analytics, anomaly detection, forecasting, and evidence-backed investigation.`
- Add topics: `python`, `sql`, `streamlit`, `power-bi`, `data-analytics`, `forecasting`, `anomaly-detection`, `llm`, `telecom-analytics`
- Add the Streamlit demo URL to the repository About section after deployment
